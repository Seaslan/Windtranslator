01概述

WindTranslator 是一款由个人开发者自主开发的本地翻译软件，提供四种翻译功能：

  • AI 翻译：通过用户自行配置的大模型 API 进行翻译；
  • API 机器翻译：通过用户自行配置的机器翻译服务 API 进行翻译；
  • 图片翻译：通过用户自行配置的 OCR / 视觉 API 识别图片文字并进行翻译；
  • 离线翻译：使用本地翻译引擎，首次使用前需联网下载翻译模型；模型下载完成后，翻译全程在本地进行、无需网络。
一句话总结 前三种功能必须由您手动填入第三方 API 密钥才能使用；待翻译的内容仅在您主动选择在线翻译时，才会被发送至您自行配置的第三方服务。软件本体不收集任何数据；离线翻译除首次下载翻译模型外全程不联网。

02我们收集什么

简单直接的回答：什么都不收集。

  • 我们不注册账号，不需要您提供姓名、邮箱、手机号等任何个人信息。
  • 我们不使用任何形式的遥测、统计或分析 SDK，没有“匿名使用数据”。
  • 我们不设任何接收用户内容的服务器，没有任何将您的翻译内容传输给开发者的通道；离线翻译所需的模型文件仅通过公开的分发源（如开源模型仓库、GitHub Releases 等）提供下载。
  • 我们不显示广告，也没有与广告相关的数据追踪（如广告 ID）。
  • 我们不写入 Cookie，本软件也没有可记录行为的 Web 服务。

换句话说，WindTranslator 是“本地优先（local-first）”软件：除首次下载翻译模型外，安装、启动、翻译的全过程均可在断网状态下完成，翻译功能不依赖开发者的任何在线基础设施。

03您的数据如何被处理

根据您选择的翻译模式，待翻译的文本和图片会走完全不同的路径：

功能 数据流向 需要网络 发送给谁
AI 翻译 文本 → 您配置的大模型 API 在线 仅发送至您自行填写的 API 服务商
API 机器翻译 文本 → 您配置的翻译服务 API 在线 仅发送至您自行填写的 API 服务商
图片翻译 图片 → 您配置的 OCR / 视觉 API 在线 仅发送至您自行填写的 API 服务商
离线翻译 文本 → 本地翻译引擎（本机处理） 翻译时离线
仅模型下载时在线		 翻译内容不发送给任何一方；仅模型下载请求发送至模型分发源

关键承诺

  • 主动触发：只有在您主动选择使用在线翻译功能时，内容才会被发送。软件不会在您不知情的情况下后台发送任何内容。
  • 开发者不可见：发送到第三方 API 的数据由您与对应服务商之间直接传输，开发者无法查看、截取或存储这些内容。
  • 翻译后即弃：除必要的本地缓存（见下节）外，软件不保存您的翻译记录或历史。
  • 模型下载不含内容：离线翻译所需的模型下载仅传输模型文件本身，不包含您的任何文本、图片或个人信息。
请注意 一旦您选择在线翻译，您的内容将受到您所选第三方服务商自身隐私政策与条款的约束。我们建议您在配置密钥前，阅读对应服务商（如 OpenAI、DeepL、Google、百度等）的隐私政策与服务条款。

04API 密钥的保存与安全

  • 仅存本地：API 密钥只保存在您的本地设备上（写入您设备上的配置文件，并使用操作系统的安全机制进行保护）。
  • 不传输给开发者：密钥不会上传、同步或传输给开发者，也不会出现在任何统计数据中。
  • 不经第三方转发：密钥仅用于在您本机上直接调用您所配置的服务商 API，不经过任何中间服务器。
  • 由您掌控：您可以随时在软件设置中查看、修改或删除您的 API 密钥。
  • 卸载即清除：卸载软件或删除其配置目录后，本地保存的密钥即被移除。
建议 请妥善保管您的 API 密钥。密钥等同于您在这些服务商处的账户凭据，任何获得该密钥的人都可以使用您的账户额度。请勿将配置文件分享给他人，也不要在公开场合粘贴密钥内容。

05离线翻译：本地处理，模型需先下载

离线翻译功能使用运行在您本机上的翻译引擎。为了让引擎能够工作，您需要在首次使用前联网下载翻译模型：

  • 首次使用前需联网：软件会从模型分发源下载翻译模型文件。该下载仅涉及模型文件本身，不会上传您的任何文本、图片或个人信息。
  • 一次下载、长期可用：模型下载到本地后长期保存，可重复使用；仅在模型发布更新且您主动选择时才会重新下载。
  • 翻译全程本地：模型下载完成后，翻译过程完全在本机进行——待翻译文本不会离开您的设备，不建立任何网络连接，无任何数据包发送或接收。
  • 不留痕迹：不记录翻译历史，翻译完成后内容即被释放。
  • 断网可用：只要模型已下载，即使完全断开网络，翻译功能也可正常使用。

为保证“离线”的纯粹性，软件仅在您主动执行“下载模型”操作时建立网络连接，翻译过程中不会在后台悄悄联网。如果您希望绝对确认，可在系统防火墙或任务管理器中对 WindTranslator 进行网络行为监控。

06数据安全措施

尽管软件不收集数据，我们仍采取以下措施保护您设备上的本地数据：

  • 本地存储保护：API 密钥存储在受操作系统权限保护的本地配置中，并对关键字段进行脱敏显示。
  • 安全传输：所有与第三方 API 及翻译模型分发源的通信均通过 HTTPS（TLS 加密）进行，防止内容在传输途中被窃听或篡改。
  • 最小权限：软件仅申请运行所必需的权限，不访问通讯录、定位、短信、麦克风等无关数据。
  • 代码开源：WindTranslator 的源代码公开可查，任何安全研究人员都可以审查其数据处理逻辑。我们欢迎并感谢通过负责任披露方式提交的安全问题报告。

由于软件不持有任何用户数据，因此不存在“数据泄露”的传统风险面；您设备本身的安全（如系统密码、设备丢失等）由操作系统安全机制与您的使用习惯共同保障。

07第三方服务免责声明

WindTranslator 本身不提供任何在线翻译服务。在线翻译功能仅作为“客户端”，将请求转发至您自行选择并配置的第三方服务商。

  • 第三方服务商独立于本软件运营，其服务可用性、稳定性、内容质量及安全水平不在我们的控制范围内。
  • 您在第三方服务商处产生的费用（包括但不限于 API 调用费、订阅费等）由您与该服务商自行结算，与本软件无关。
  • 您发送至第三方服务商的内容，其收集、使用、存储与披露行为受该服务商自身隐私政策约束，开发者不承担相应责任。
  • 因第三方服务商服务中断、政策变更、数据泄露或任何其他原因造成的损失，开发者不承担责任。

我们建议您在配置任何第三方 API 之前，仔细阅读并理解对应服务商的最新隐私政策与服务条款。

08儿童隐私

WindTranslator 不面向 13 周岁以下的儿童设计，也不提供任何针对儿童的在线服务或社交功能。

由于软件不收集任何用户的个人信息（包括儿童的个人信息），本软件不存在收集、使用或共享儿童数据的行为。如果您是家长或监护人，并认为您的孩子在使用本软件时向第三方服务商提供了个人信息，请直接联系相应的第三方服务商处理，或联系我们以便我们提供必要的协助。

09本政策的更新方式

我们可能会不时更新本隐私政策，以反映软件功能的变化或法律法规的要求。更新方式如下：

  • 每次修订都会更新本页面顶部的“生效日期”；
  • 重大变更会在软件的新版本说明（Release Notes）中予以标注；
  • 本政策的历史版本可通过软件的版本控制仓库（Git 提交历史）查阅。

继续使用软件即表示您知悉并接受更新后的政策。由于本政策可能发生变更，我们建议您定期查阅本页面。
